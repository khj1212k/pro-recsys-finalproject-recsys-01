## 1. 요약

1. **노출 재정렬(P1)**: ranker v2 nDCG@10 **0.6551** [0.6533, 0.6569], AUC 0.7849. 가장 강한 베이스라인
   popularity_24h(0.5992) 대비 **+0.0559** [+0.0547, +0.0573], 팀 방식 재현(team_binary, 0.3952) 대비 +0.2598.
2. **가장 큰 기여는 모델이 아니라 학습 데이터 구성이었다.** ablation 6단계 중 "무작위 네거티브 → 실제 노출 비클릭
   네거티브"가 +0.1868, trailing 인기도가 +0.0571, 단기·세션 벡터가 +0.0088, 카테고리 share·히스토리 길이가 +0.0089.
   binary → LambdaRank(유저 그룹)는 +0.0010, 유저 그룹 → 노출 그룹은 −0.0027로 사실상 차이가 없었다.
3. **네거티브 분포가 과제를 정의한다.** 노출 비클릭으로 학습한 ranker v2는 48h 전체 풀 랭킹(P2)에서 nDCG@10 0.0530으로
   popularity_6h(0.1168)보다 못했다. 같은 피처로 48h 풀 무작위 네거티브를 쓴 `ranker_v2_poolneg`가 P2에서
   **0.2686** [0.2640, 0.2728](popularity_6h 대비 +0.1518, team_binary 대비 +0.0872)였고, 대신 P1에서는 무작위 수준(AUC 0.5025)이었다.
   서빙 모델은 validation을 보지 않는 사전 등록 규칙(es 구간 표본)으로 `ranker_v2_poolneg`가 선택됐다.
4. **요청 시점 프로필 갱신**: 같은 날 앞선 이벤트가 있는 노출(평가 노출의 68.9%, 168,570건)에서 실시간 프로필로
   학습·서빙한 ranker v2가 일 배치 프로필로 학습·서빙한 ranker v2보다 nDCG@10 **+0.0100** [+0.0094, +0.0106].
   단, 히스토리 평균 벡터 코사인만 쓰면 실시간 갱신이 오히려 −0.0027이었다 — 이득은 단기·세션 피처를 학습으로 결합한 데서 나온다.
5. **MMR(성승우 구현 재사용)**: λ 1.0 → 0.5에서 nDCG@10 −0.0025(상대 −1.0%), ILD +0.0094(+1.4%), 카테고리 엔트로피
   +0.073(+4.0%), coverage 변화 없음. 사전 등록 규칙의 권장 λ는 0.5지만 효과 자체가 작다.
6. **ADR 0013 승격 규칙 R1–R4 모두 통과**(아래 7절). 서빙 활성화는 이 벤치마크 밖 조건(서빙 어댑터 parity, 한국어 전이
   점검)이 남아 있어 shadow부터 시작한다.
7. **보충 실험 v1.1**(부록 A, 실행 전 등록): 네거티브를 48h 풀로 고정하면 P2에서 trailing 인기도 +0.0494, 단기·세션 +0.0234,
   카테고리 share·히스토리 길이 +0.0147로 모든 피처 단계가 기여한다. 같은 팀 피처에서는 binary+7일 무작위 네거티브(0.1814)와
   LambdaRank+48h 풀 네거티브(0.1812)가 같아, P2에서 팀 방식 대비 +0.087은 전부 피처에서 온다. MMR λ=0.5는 λ=1.0 대비
   ILD +0.0094 [+0.0090, +0.0099](이득 측정됨), nDCG@10 −0.0025 [−0.0057, +0.0008](비용은 측정되지 않음).

## 2. 데이터·프로토콜

- 창: fit 2023-05-20T07 ~ 05-24T07(train 창 시작 + 48h부터, 48h trailing 인기도가 로그 시작 이전으로 잘리지 않도록),
  es 05-24T07 ~ 05-25T07(train 마지막 24h), test = validation 창 전체 05-25T07 ~ 06-01T07(고정 정답 창).
  평가 데이터는 모델 선택·early-stop·하이퍼파라미터 어디에도 쓰지 않았다(하이퍼파라미터는 팀 설정 고정).
- point-in-time: 유저 피처는 요청 시각 t보다 엄격히 이전 이벤트(split별 history 21일 + 행동 창 클릭), 아이템 인기도는
  t 이전의 행동 로그 클릭/노출만. 반열린 구간 [.., t)는 `recsys_core` 단위 테스트(미래·동시각 이벤트 누출 없음)로 고정했다.
- **클릭 시각 근사**: EB-NeRD 행동 로그에는 클릭 시각이 없어 클릭을 그 노출의 시각에 둔다(`loaders.click_events`).
  실제 클릭은 노출 뒤(그 페이지에 머무는 동안)에 일어나므로, t의 trailing 인기도·CTR은 t 직전 노출에서 나와 실제로는
  t 뒤에 일어난 클릭을 셀 수 있다. 즉 "point-in-time"은 노출 시각 기준이며, 클릭 지연(초~분) 규모의 경계 효과가 모든 모델·
  베이스라인의 인기도 피처에 같이 걸려 있다. 크기 점검은 부록 B.
- novelty@10 정의: 목록 상위 10개 기사의 self-information −log2 p 평균, p = (그 기사의 t 기준 48h 클릭 수 + 1) /
  Σ(요청 풀 안 모든 후보의 48h 클릭 수 + 1). 전체 카탈로그가 아니라 **요청 자신의 후보 풀 안** 점유율이라 표준 정의(전체 유저 대비
  클릭 비율)와 다르고 풀 크기에 따라 값의 범위가 달라진다. 같은 풀을 쓰는 방법끼리만 비교한다.
- seen: 평가 후보 중 유저가 t 이전에 이미 읽은 기사는 **4.68%**, 클릭된 기사 중 이미 읽은 기사는 **2.48%**
  (노출의 2.49%가 해당). P1은 seen 포함/제외 둘 다, P2는 풀에서 seen을 뺀 뒤 평가했다.
- P2 풀: 요청 시각 기준 48h 이내 발행 기사, 평균 235개(161~279). 클릭 기사의 94.6%가 이 창 안에서 발행됐고,
  seen 제거 후 도달 가능한 정답은 92.7%(Recall 상한). seen 제거로 빠진 정답 372건 / 20,091건.

## 3. 임베딩 (BGE-M3, 덴마크어)

- 입력 = 제목 + 부제 + 본문을 512 토큰에서 절단. 토큰 길이 중앙값 497, 48%가 512 초과.
  512 초과 기사 100건을 2048 토큰으로 다시 임베딩한 벡터와의 코사인 평균 0.961(p05 0.896, 최소 0.853).
- 처리량: M2 MPS fp16, 배치 32에서 2.28건/s(동시에 다른 작업이 돌던 공유 머신, 재개 후 11,522건 기준). 2048 토큰은 0.74건/s(배치 4).
- BGE-M3는 다국어 모델이지만 덴마크어 성능을 따로 보증하지 않으므로 카테고리 kNN으로 점검했다:

| k | 기사 수 | 카테고리 수 | kNN LOO 정확도 | 다수 클래스 비율 |
|---|---|---|---|---|
| 10 | 20738 | 25 | 0.8458 | 0.2096 |

  사전 등록 기준(≥0.6이고 다수 클래스보다 높음)을 넘는다. 즉 코사인 계열 피처가 약한 것은(아래 P1/P2) 임베딩이
  덴마크어를 못 읽어서라기보다 "주제 유사도" 자체가 클릭을 잘 설명하지 못하기 때문으로 본다.

해석(사전 등록 규칙: CI > 0 기여 / < 0 해로움 / 0 포함 구분 불가):
- **binary → LambdaRank(유저 그룹)**: +0.0010 — CI상 기여지만 크기는 무시할 만하다. ADR 0003이 기대한 "랭킹 손실 직접 최적화"의
  효과는 무작위 네거티브 과제에서는 거의 없다.
- **유저 그룹 → 노출 그룹**: −0.0027 — 해로움(작음). 무작위 네거티브 과제에서는 쿼리 단위가 별 의미가 없다.
- **무작위 → 실제 노출 비클릭 네거티브**: **+0.1868** — 압도적. 팀 방식 모델은 기사 나이(`hours_since_pub` gain 82%, 3 seed 평균 gain 비율)로 "클릭 vs
  7일 풀 무작위 기사"를 가르는 법을 배웠고(es AUC 0.97), 이미 신선한 기사끼리 경쟁하는 노출 목록 안에서는 무작위보다 못했다(AUC 0.4671).
  이 단계의 best_iteration이 17~26으로 짧은 것은 팀 피처만으로는 노출 안 순위에 쓸 신호가 적다는 뜻이다.
- **+trailing 인기도**: +0.0571 — 두 번째로 큼. ranker v2의 gain 상위는 `pop_clicks_6h`(26%), `pop_ctr_24h`(22%)(3 seed 평균 gain 비율).
- **+단기·세션 벡터**: +0.0088, **+카테고리 share·히스토리 길이**: +0.0089 — 작지만 CI가 0을 넘는 개인화 기여.
- seed 표준편차는 모든 모델에서 ≤0.0016(nDCG@10 등 최대)으로 CI 폭보다 작다.

(+0.1518 [+0.1464, +0.1573], 5.3절) 그것은 규칙이 요구한 비교가 아니다. 다음 사전 등록 실험의 게이트는 ADR 0013 A2에 적었다.

## 9. 해석과 한계

- **EB-NeRD는 이 서비스가 아니다.** 덴마크 타블로이드 한 곳의 편집 프런트 페이지, 1주 평가 창 하나, 약 1.5만 유저 표본이다.
  split은 하나뿐이라 CI는 "이 주의 유저 표집 변동"만 반영한다(다른 주·다른 매체로의 일반화는 모른다).
- **노출 편향**: EB-NeRD 클릭은 편집자가 보여준 기사에서만 생긴다. P2 정답(클릭)은 노출 정책에 묶여 있어, 풀 네거티브로 학습한
  모델은 선호뿐 아니라 "Ekstra Bladet이 무엇을 노출하는가"(`pop_clicks_6h` gain 50%, 3 seed 평균 gain 비율)도 배운다. P1은 노출 조건부라 이 편향이
  없지만 서빙 조건(전체 풀)과 다르다. 이 서비스의 진짜 서빙 성능은 두 수치 사이 어딘가이며, 노출 로그에 탐색 슬롯·propensity를
  남겨 온라인으로 확인해야 한다.
- **인기도 의존**: ranker v2의 이득 대부분이 trailing 인기도에서 온다. 사용자가 적은 초기 서비스에서는 인기도 신호가 약하므로
  상대 이득이 그대로 옮겨진다고 볼 수 없다.
- **팀 방식 재현은 적응판이다**: 7일 발행 풀 제한(EB-NeRD 카탈로그가 수년치라 필요), 온보딩 카테고리 대신 행동 창 이전 상위 3개
  카테고리, 나이·성별은 EB-NeRD 값. 팀 코드 자체를 팀 데이터에서 돌린 결과가 아니다.
- 하이퍼파라미터 튜닝 없음(팀 설정 고정). 학습형 유저 인코더(NRMS 등)와는 비교하지 않았다.
- es 구간(train 마지막 24h)은 early-stop과 P2 모델 선택에 함께 쓰였다(사전 등록대로). 모든 모델이 같은 창에서 early-stop했으므로
  5.1절 선택 점수는 공통으로 약간 낙관적일 수 있다. 선택 모델과 2위의 차이(0.2967 vs 0.2593)는 seed별로도 겹치지 않는다.
- 아직 없는 것: 일일 배치 릴리스 regime(P3), 콜드 유저 히스토리 절단 곡선, 언어 전이(요청 내 랭크 정규화) 점검,
  하이퍼파라미터 튜닝. (P2 풀 네거티브 사슬과 MMR 쌍체 차이는 부록 A에서 보충.)

## 10. 이력서에 쓸 수 있는 문장 / 쓰면 안 되는 문장

**쓸 수 있는 문장** (모두 [EB-NeRD] 라벨과 함께):
- "공개 뉴스 추천 벤치마크 EB-NeRD(small, 평가 24.5만 노출·1.5만 유저)에 point-in-time 평가 하네스를 만들고, 평가 규칙과
  승격 조건을 결과 전에 ADR로 커밋한 뒤 3 seed·유저 부트스트랩 95% CI로 7단계 ablation을 측정했다."
- "팀 방식 LightGBM(EB-NeRD 적응판 재현, binary + 무작위 네거티브)을 ranker v2(LambdaRank, 실제 노출 네거티브, trailing 인기도, 단기·세션 피처)로
  바꿔 노출 재정렬 nDCG@10을 0.395 → 0.655로 올렸다(인기도 베이스라인 0.599 대비 +0.056, 95% CI [+0.055, +0.057])."
- "ablation으로 개선의 대부분이 목적함수가 아니라 네거티브 구성(+0.187)과 trailing 인기도(+0.057)에서 온다는 것을 보였고,
  노출 네거티브 모델이 전체 후보 풀에서는 인기도보다 못하다(0.053 vs 0.117)는 것을 확인해 서빙 후보 분포에 맞춘 네거티브로
  학습한 모델(0.269)을 검증셋을 보지 않는 사전 등록 규칙으로 골랐다."
- "서빙과 같은 전체 후보 풀 조건에서 피처 기여를 따로 측정했다: 팀 피처 0.181 → trailing 인기도 +0.049 → 단기·세션 +0.023 →
  카테고리 분포 +0.015 (nDCG@10, 모두 95% CI > 0), 같은 피처에서는 목적함수·네거티브 교체 효과가 없었다."
- "요청 시점 프로필 갱신의 가치를 재생 실험으로 측정했다: 같은 날 앞선 이벤트가 있는 노출(69%)에서 nDCG@10 +0.010
  (95% CI [+0.009, +0.011]). 장기 프로필 벡터만 갱신하면 오히려 −0.003이었다."
- "오프라인 평가와 요청 시점 서빙이 공유하도록 point-in-time 피처 코어(numpy만, 미래 이벤트 누출 테스트·팀 피처와 parity 테스트)를 만들었다."

**쓰면 안 되는 문장**:
- EB-NeRD 리더보드/RecSys Challenge 순위와의 비교, "SOTA", "AUC 0.78 달성"을 공식 수치처럼 쓰는 것 — split·정답 창·피처 조건이 다르다.
- "서비스 CTR/정확도 X% 향상", "한국어 뉴스레터 추천 성능" — 이 서비스에서는 측정하지 않았다.
- "LightGBM 추천 모델 배포/운영" — shadow 전 단계다(서빙 어댑터 parity·언어 전이 점검 전).
- "MMR로 다양성을 크게 개선" — ILD +1.4%(쌍체 CI > 0), 카테고리 엔트로피 +4% 수준이다. "정확도 손실 없이"도 쓰지 않는다:
  손실이 측정되지 않았을 뿐(CI가 0을 포함) 없다고 보인 것이 아니다.
- "팀 모델이 무작위보다 못했다" — EB-NeRD에 맞춘 팀 방식 재현(적응판) 결과이지 팀 모델을 팀 데이터로 평가한 결과가 아니다.
- "딥러닝(NRMS 등)보다 낫다" — 비교하지 않았다.
- "실시간 추천이 크게 좋아졌다" — 오프라인 재생에서 nDCG@10 +0.010이다.
- "미래 정보 누출이 전혀 없는 평가" — 시각 기준 point-in-time이지만 클릭 시각이 없어 노출 시각으로 근사했다(2절, 부록 B).

- **5분 가드**: 창 끝을 5분 당기면 근사로 섞였을 수 있는 클릭 대부분과 함께 정상적인 최근 5분 클릭도 빠진다. 그래도 인기도
  베이스라인 nDCG@10 변화는 P1에서 −0.0021 ~ −0.0027, P2 popularity_6h에서 −0.0031 [−0.0037, −0.0026]이다. 근사가 베이스라인

- **모델은 재지 않았다**: ranker v2 계열은 인기도 피처 비중이 커서(`pop_clicks_6h` gain ranker_v2 26%, poolneg 50%, 3 seed 평균

  최근 5~30분 클릭을 뺀 비용이다. 인기도 신호가 최근 수십 분에 크게 의존한다는 뜻이고, 서빙에서 인기도 집계가 늦을 때의 비용을
  가늠하는 참고치다(베이스라인 기준, 이 서비스 데이터 아님).
