# 범위 종결 — 열린 항목 정리와 취업 전 계획에 없는 것 (2026-10-18)

이 문서는 설계 문서가 아니라 **정리 기록**이다. ADR·리포트·문서에 흩어져 있던 "재실행 대기"·"결과 대기"·"TODO"·"구현 전"·"사용자 결정 대기" 성격의 열린 항목을 찾아
하나씩 **완료 / 유보 / 폐기**로 닫고, 각 원문 위치에 한 줄로 같은 판정을 적었다(원문에 `범위 종결 C-nn`을 적은 줄을 남겼다). 36건을 모두 닫았다 - **열린 항목은 0건**이다(C-19는 앞의 셋을 유보로, 프런트 타입 검사는 2026-10-25 CI 잡으로 닫았다). 이 문서를 처음 쓸 때는 C-16·C-19·C-35가 열려 있었고(열린 것 3건),
같은 날 C-16은 PR #48로, C-35는 README 정합 PR로 닫았다 - 각 행의 "2026-10-18 갱신". C-19의 프런트 타입 검사는 2026-10-25에 닫았다(그 행의 갱신). 효력 있는 결정은 여전히 ADR이다 -
이 문서의 판정이 ADR 본문과 다르면 ADR이 옳다. 이 정리가 정한 것은 열린 항목의 상태 표기뿐이고, 결과와 결정은 ADR이 말한 그대로다. 폐기와 유보의 근거는 소유자의 범위 동결(2026-10-18)과 ADR·리포트에 적힌 결과다.

핵심 한 줄: **취업 전 계획에서 새 실험·새 사전 등록·새 하네스를 더하지 않는다.** E0(기준선 + 자동 라벨), 한국어 임베딩 점검, E15는 결과가 났고, M5(실제 shadow 등록 제외)와 호스트 밖 백업·복원 검증은 코드·도구까지 들어갔다.
그 밖의 열린 항목은 아래 표의 조건이 생기기 전에는 열지 않는다.

## 1. 판정 방식과 범위

| 판정 | 뜻 |
|---|---|
| 완료 | 했거나, 다른 증거로 대체됐다. 근거 링크를 적었다 |
| 유보 | 하지 않았고 지금 하지 않는다. **다시 열 조건**을 적었다. 조건이 생기기 전에는 그 일을 전제로 한 문장을 쓰지 않는다 |
| 폐기 | 하지 않기로 했다. 이유를 적었다 |
| 열림 | 이 정리가 닫지 않았다. 누가 어디서 닫는지를 적었다. 계획에 있는 일이거나 다른 파일의 몫이라 유보(= 지금 하지 않음)가 아니다 |

**무엇을 열린 항목으로 셌나.** 앞으로 할 일, 결과를 기다리는 일, 결정을 기다리는 일로 쓰인 문장: "재실행 대기", "결과 대기", "TODO", "미구현", "구현 전·시작 전·실행 전",
"사용자 결정 대기·승인 대기", "(예정)", "후속 작업·남은 일", 그리고 ADR 상태가 "제안됨"인 채 채택 조건이 남은 것. 찾는 데 쓴 명령은 7절에 있다.
**세지 않은 것.** "측정하지 않았다·확인하지 않았다"로 쓴 한계 문장은 열린 일이 아니라 **주장 범위의 경계**다(각 ADR의 "결과와 한계"가 기준). 이 목록으로 닫지 않으며,
그 경계를 넘는 문장을 쓰지 않는 것으로 지킨다. 완료된 일의 역사 기록(변경 기록·운영 기록의 당시 상태 서술)은 고치지 않았다.

## 6. 이 문서가 닫지 않는 것 · 소유자 몫

- README·`docs/case-studies/`·`docs/evidence-summary.md`·`docs/assets/`는 이 정리의 처음 판에서 고치지 않았다. 그 뒤 README 정합 PR이 고쳤다(C-35, 자동 라벨 정정 PR #49 반영 포함).
- 코드·CI·핀·레거시 삭제는 하지 않았다. 코드가 필요했던 정합 패치(C-16)는 PR #48이 했다. 그 뒤 PR #51(2026-10-18)이 HyperCLOVA 레거시를 지우고, ADR 0010 Addendum의 열린 항목 둘(bake-off 사전 등록 개정 A9.1 기록, E0 리포트의 새 `failure_reason` 분류)을 닫았다. 코드·CI 변경이 필요한 열린 항목은 C-19의 프런트 타입 검사뿐이다.
- 소유자가 직접 해야 닫히는 유보 항목: C-09(공공데이터포털 신청), C-14(ADR 0036 승인),
  C-32(운영 확인 일정 - 2026-10-25에 위임 아래 읽기 전용으로 확인했으나 소유자 확인은 아직), **C-36(2.6절 밖 위치 3곳 승인 - `full/`은 2026-10-18 승인·켬)**.
  C-12는 PR #43 병합(2026-10-18)으로 "대조 불가"로 종결됐다.
- 날짜가 정해진 소유자 확인: Mac `data/backups/`의 옛 덤프 세 개를 만료일에 지운다 - `mac-compose-2026-09-26.dump` 2026-10-25, `tier0-micro-2026-09-26T2218.dump`와
  `tier0-micro-2026-10-16T1927Z.expires-2026-10-26.dump` 2026-10-26(ADR 0023 "기존 덤프 2개" 행, 런북 6.5 "옛 절차", `docs/runbook.md` 8절의 확인 한 줄). `mac-compose-…dump`는 본문 없는 부분을 남길지도 소유자가 정한다.
